## Summary

On June 14, 2026, the `jpmap` CRAN preparation led to the design and creation
of a separate companion data package, `jpmapdata`. The reason was simple:
large boundary files should not be redistributed every time the main `jpmap`
functionality package is updated. The data package was therefore created as a
small, CRAN-facing package containing boundary `GeoPackage` files used by
`jpmap`.

## User Prompt Summary

The user wanted `jpmap` to be CRAN-friendly and understood that CRAN might not
want large map data repeatedly stored in the main package. During the broader
June 14 `jpmap` work, the package design shifted toward a split:

- `jpmap`: functions, transforms, plotting helpers, vignettes, and user-facing
  documentation.
- `jpmapdata`: bundled boundary data that `jpmap` can discover when installed.
