The user wanted a separate companion data package for `jpmap` so large boundary
files could live outside the main package. The package should support `jpmap`
examples and tutorials while reducing the need to repeatedly redistribute large

- Set package license to `CC BY 4.0`.
- Added GitHub `URL` and `BugReports` fields.

- Added `inst/extdata/jpmap_boundaries_2021.gpkg`.

  Prefecture from official MLIT N03 administrative-area data.
- Added `R/jpmapdata.R` with exported helpers:
  - `jpmapdata_dir()`
  - `available_jpmapdata()`
- Added `R/prefectures.R` with prefecture-code/name lookup data.
- Added Rd documentation in `man/`.

Package-design decisions:

- Keep large boundary files in `jpmapdata` rather than bundling them directly in
  `jpmap`.
- Include a smaller first set of bundled files rather than the national 2024
  municipal GeoPackage, because the national file is very large.
- Let users build all-prefecture municipal boundaries locally with
  `jpmap::jpmap_build_data(year = 2024)` when needed.
